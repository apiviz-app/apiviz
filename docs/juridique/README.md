## Ce qu'il faut fournir pour remplir les crochets

- **Structure** : dénomination, forme (micro-entreprise, SASU, EURL…), capital, SIREN / RCS, adresse du siège, numéro de
  TVA intracommunautaire (ou mention « TVA non applicable, art. 293 B du CGI » en franchise).
- **Contact** : une adresse e-mail dédiée (par exemple contact@apiviz.fr) et, pour les CGV, un téléphone.
- **Directeur de la publication** : en général le dirigeant.
- **Médiateur de la consommation** : nom, site, adresse (adhésion à souscrire avant de vendre aux particuliers).
- **Prestataire de paiement** (D-14).
- **Décisions** marquées `[DÉCISION]` : durée de conservation des comptes inactifs, mode d'essai gratuit, juridiction.

## Règles d'écriture

Vouvoiement (comme `confidentialite.html`), phrases courtes, pas de jargon sans explication. Chaque document porte une
date de version ; toute modification qui touche les droits des utilisateurs est annoncée dans l'application.
